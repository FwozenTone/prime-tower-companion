Prime Tower Wizard

One project. One selected plate. An adaptive tower for up to twelve tools with separate material sections, checked after slicing.

1 · Choose your project

Orca location

This location is used for both slicing and opening the project, and is remembered between runs.

Save your print-quality settings in the 3MF first. Variable layer heights are copied from the reference slice. Do not change layer settings after generating the tower. Turn off arc fitting. Independent layer grids must fit every tower nozzle’s layer-height limits. The tower gets a 15 mm outer brim with zero gap. Other plates remain in the output project. The original is never overwritten.

Tower options

Width is the long dimension of each internal rectangle. Rib size is the side of each rounded outer rib. Section depth grows when needed to provide the requested minimum volume on the thinnest layer. The final audit checks actual priming volume; this is not an exact-volume dispenser.

Read the project to list its filament types, including dedicated support materials. Support selection must match the reference slice. Automatic frame preference: PPS, PEEK, PEI, PC, ASA, ABS, PETG, PLA, then nylon. This is a starting choice, not a strength rating; override it for your filament and print conditions. Dedicated support and flexible filaments are excluded from the frame. Idle sections use only the identical material type; blends stay separate. Every material is maintained on every tower layer.

3 · Guided manual export
Use these steps if Orca cannot slice automatically, or if you prefer to position the tower yourself.
A. In Orca, open the original 3MF, select the same plate number shown above, slice it, and export plain G-code.


B. Open the generated tower project using the button above. Move the entire IPT_ASSEMBLY if needed, save at the same filename, slice the selected plate, and export G-code. Keep Print by layer and As object list enabled, with the tower first.


The audit allows any filament order. It checks the first XY destination and first extrusion after each tool pickup, material separation, section coverage, and priming before model/support extrusion. Failed checks stay visible and do not count as a verified result.


Runs locally on your computer. No uploads and no print commands. Keep the launcher running while using this window. Firmware-internal pickup movements and physical print quality are outside the audit.
