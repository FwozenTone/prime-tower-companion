Prime Tower Wizard

One project. One selected plate. An adaptive tower for up to twelve tools with separate material sections.

Create a prime tower

Orca location

This location is used for both slicing and opening the project, and is remembered between runs.

Save your print-quality settings in the 3MF first. Variable layer heights are copied from the reference slice. Do not change layer settings after generating the tower. Turn off arc fitting. Independent layer grids must fit every tower nozzle’s layer-height limits. The tower gets the selected outer brim with zero gap. Other plates remain in the output project. The original is never overwritten.

Tower options

Width is the long dimension of each internal rectangle. Rib size is the side of each rounded outer rib. Section depth grows when needed to provide the requested minimum volume on the thinnest layer.

Read the project to list its filament types, including dedicated support materials. Support selection must match the reference slice. Automatic frame preference: PPS, PEEK, PEI, PC, ASA, ABS, PETG, PLA, then nylon. Dedicated support and flexible filaments are excluded from the frame.

Guided manual export
